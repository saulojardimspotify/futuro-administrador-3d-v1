# 🎓 Futuro Administrador — v1 (bonecos de blocos)

Jogo 3D de corrida no navegador: um aluno de Administração corre pelo corredor da faculdade,
pega 25 disciplinas, desvia de reprovações, festas e bebidas e recebe o diploma no auditório.

**Jogar:** https://saulojardimspotify.github.io/futuro-administrador-3d-v1/

## Controles
- ← → (ou A/D): trocar de faixa
- Espaço / ↑ (ou W): pular
- M: ligar/desligar o som
- Celular: deslizar o dedo

## Tecnologia
HTML + [Three.js](https://threejs.org/) r128. Sem instalação: basta abrir o `index.html`.

## Versões
Esta é a **v1**, com bonecos montados em código (blocos arredondados com rosto desenhado).
A versão com personagens 3D realistas está em https://github.com/saulojardimspotify/futuro-administrador-3d
